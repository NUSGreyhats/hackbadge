# HackBadge

Badge designed for HackBash 2025.

## Set Up
Clone the repositories with submodules:
```bash
git clone --recurse-submodules https://github.com/NUSGreyhats/hackbadge.git
```

If you have already cloned the repository, initialize the submodules by running: `git submodule update --init --recursive`.
